# Project Manager — Система управления проектами

Веб-приложение для управления проектами и задачами, разработанное в рамках расчётно-графической работы по дисциплине «Технологии и методы программирования».

## Функциональность

- **Регистрация и аутентификация**: с подтверждением по email
- **Трёхуровневая система доступа**: администратор, менеджер, пользователь
- **Управление проектами**: создание, просмотр, редактирование проектов
- **Управление задачами**: создание задач, назначение статусов и приоритетов
- **Учёт времени**: фиксация затраченных часов по задачам
- **Форум обсуждений**: для каждого проекта отдельная ветка
- **Поиск задач**: по названию, описанию, статусу и приоритету
- **Статистика**: диаграммы выполнения проектов, трудозатраты
- **Email-уведомления**: об изменении статуса задач и новых сообщениях

## Технологии

| Компонент | Технология |
|-----------|------------|
| Язык | Java 17 |
| Фреймворк | Spring Boot |
| Доступ к данным | Spring Data JDBC |
| База данных | PostgreSQL |
| Миграции | Flyway |
| Клиентская часть | HTML, CSS, Bootstrap, JavaScript |
| Сборка | Maven |

## Запуск проекта

### Требования
- Java 17 или выше
- PostgreSQL 14 или выше
- Maven 3.8+

### Шаги для запуска

1. Клонировать репозиторий
   ```bash
   git clone https://gitflic.ru/vadimnekterov-wq/project-manager.git
   cd project-manager
2. Создать базу данных PostgreSQL
   CREATE DATABASE project_manager;
3.Настроить подключение к БД в src/main/resources/application.properties
4.Запустить приложение
   mvn spring-boot:run
5.http://localhost:8080
